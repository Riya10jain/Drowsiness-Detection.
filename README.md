# 🚗 Drowsiness Detection System

A real-time Drowsiness Detection System that monitors a person’s eye state using computer vision and alerts them when signs of fatigue are detected. This project helps prevent accidents by ensuring driver alertness.

---

## 📌 Overview

Drowsiness while driving is one of the leading causes of road accidents. This project uses OpenCV and Machine Learning techniques to detect eye closure and trigger an alert when the driver appears sleepy.

---

## ✨ Features

- Real-time eye detection using webcam  
- Detects eye closure and blinking patterns  
- Audio alert when drowsiness is detected  
- Fast and lightweight system  
- Easy to run and customizable  

---

## 🛠️ Tech Stack

- Programming Language: Python  
- Libraries & Tools:
  - OpenCV  
  - NumPy  
  - Dlib / Haar Cascade  
  - Pygame (for alert sound)

1. Clone the repository

2. Navigate to the folder
cd Drowsiness-Detection

3. Install dependencies
pip install -r requirements.txt

4. Run the project
python drowsiness.py

---

## 🚀 How It Works

1. Captures real-time video using webcam  
2. Detects face and eyes using Haar Cascade / Dlib  
3. Monitors eye aspect ratio (EAR)  
4. If eyes remain closed for a certain duration, an alarm is triggered
