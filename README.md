# Smart Drowsiness Detection - Corrected (Windows)

This corrected project uses @tensorflow-models/face-landmarks-detection@1.0.6 and the createDetector API.

## Run on Windows
1. Extract the ZIP.
2. Open the folder in VS Code.
3. In terminal run:
   npm install
   npm start
4. Open http://localhost:3000 in Chrome and allow camera access.

If you see warnings about WebGL or WebAssembly, try updating Chrome.
